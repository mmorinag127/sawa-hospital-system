# Quickstart: Facility OCR Pipeline

## Goal

Validate end-to-end extraction for a single-page weekly order PDF using a registered facility template.

## Steps

1. Register a facility template with ROI definitions and matching thresholds.
2. Associate the target facility with the template version.
3. Upload a single-page order PDF to the intake location.
4. Verify a job record is created and reaches a completed status.
5. Review the structured output for quantity values, notes, and failed cells.
6. Upload a non-matching PDF and confirm it is marked unclassified with review artifacts.
