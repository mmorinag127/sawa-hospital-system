# 追加仕様 実装タスクリスト（初版）

この文書は `docs/additional-spec.md` を実装に落とし込むための作業分解。
詳細設計やSQL/画面仕様は着手時に追記する。

## A. データ/設定
- 基準メニューDB（45日サイクル）用のテーブル設計・マイグレーション作成。
- メニュー定義に「添え/付属品（ソース/マヨ）」フラグ・関連項目を追加。
- `input_example/献立メニュー 2.xlsx` のソース関連「○」を付属品フラグとして取り込む仕組みを用意。
- 施設マスターに「軟菜/常食区分（混在可の設計）」を追加。
- 施設マスターに「袋分け例外ラベル（拡張可能）」を追加。
- 袋規定量（小100g/中500g/大1500g）を可変にする保存先を設計。

## B. バックエンド
- メニュー名の「添え」パース実装（`AAA 添え BBB` を分解、数量連動、別行出力）。
- 付属品（ソース/マヨ）を数量連動で付与し、袋は1つにまとめる処理を実装。
- 総量集計（確定注文ベース、食区分別、添え/付属品/軟菜常食分離）を実装。
- 袋分けロジックに施設別例外を適用できるフックを追加。
- 納品書テンプレート: 食区分の後にメニュー名を出力、ソースは備考欄に出力。

## C. フロントエンド
- 総量ページ（新規）を作成し、日付・食区分別の総量を表示。
- 送り状画面（新規）を作成し、PDFアップロード→解析→Excel出力の導線を実装。

## D. 送り状PDF解析
- 固定フォーマットPDFの抽出ロジック実装（テキスト抽出/OCRの選定は実例で確定）。
- 出力Excel: `input_example/伝票番号管理表.xlsx` と同一フォーマットで生成。
- 施設名は施設マスター名に正規化して出力。
- 参照例: `input_example/佐川 伝票番号.pdf` → `input_example/伝票番号管理表.xlsx`

## E. テスト/検証
- 添え/付属品/軟菜常食/例外のユニットテスト。
- 総量集計の集計精度テスト（食区分別・施設混在）。
- 送り状PDFのサンプル検証（`input_example/佐川　伝票番号.pdf`）。
