# Current Projection Contracts

These are authored projection components, not live FAX accuracy or production
parity evidence. No tests have run in this implementation batch.

The shared fixture requires an explicit authored-split or repository-specimen
layout, facility, period, physical menu rows, quantity fields and blank-cell
literal. It uses real registration/context confirmation, native production,
terminal persistence and explicit selection. Every supplied field and value is
checked on its actual uniquely identified current row. An unowned diagnostic
cannot change SQL, original PDF, selected evidence or the current sheet.

Old template-registry, raw-header and positional-fallback successes are not
current authority. Their valid quantity responsibilities use current owned
sources. Their unrelated metadata remains negative input, not a fabricated
selectable result. Pure parsing components are kept separate.
